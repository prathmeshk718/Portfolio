# Portfolio (React + Tailwind CSS v4 + Vite)

## Run it
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in dist/

## Make it yours
- Content: edit `src/data.js` (name, headline, projects, skills, email).
- Colours and fonts: edit the `@theme` block in `src/index.css`
  (and the font link in `index.html`).
- Layout: each section is one file in `src/components/`.
